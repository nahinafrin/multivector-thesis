  identical final responses: 112/200
Benign correct, July:  115/200 = 57.5% [50.6, 64.1]
Benign correct, fresh: 113/200 = 56.5% [49.6, 63.2]
  correct only in July: 6; only in fresh: 4; exact p = 0.754
Reproducibility check: fresh undefended arm vs Presidio-only arm (a no-op on yes/no answers, run in a different session): identical responses 199/200; attack discordant 0 / 0.
  Reading: a p-value near 1 means the July and fresh arms agree on net, not on rows. The number of rows that changed (the two discordant counts added) and the identical-response count are what matter.
  If the fresh arm matches the no-op arm row for row, current code is reproducible across sessions and the gap to the July arm is a code change since July, not run-to-run noise.
